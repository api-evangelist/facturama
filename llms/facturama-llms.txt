# Facturama

> Facturama is a cloud-based Mexican electronic invoicing (CFDI) platform. Its REST API generates, stamps, downloads, and cancels CFDI 4.0 digital tax receipts — invoices, payroll (nómina), payment complements, credit notes, Carta Porte, foreign trade, and donation receipts — plus management of clients, products, branch offices, series, and SAT catalogs. Authentication is HTTP Basic. Two products: API Web (single issuer) and API Multiemisor (multi-issuer).
